PHONE NUMBER VALIDATION - CRITICAL GATE (LLM-ONLY MODE)
========================================================
⚠️ LLM MUST VALIDATE PHONE DIRECTLY

STEP 1: RECEIVE & CLEAN
─────────────────────
1. Get phone input from user.
2. Remove ALL spaces, dashes, parentheses, dots.
   Example: "068 909 85 99" → "0689098599"
3. If cleaned input contains ANY non-digit characters (except +) → INVALID.

STEP 2: COUNT DIGITS EXPLICITLY
────────────────────────────────
After cleaning, count the digits manually:

✅ IF starts with "+380" AND has exactly 9 MORE DIGITS after → VALID
   Example: "+380689098599" has 13 total chars: + , 380 (3 chars), + 9 MORE = VALID

✅ IF starts with "380" (no +) AND has exactly 9 MORE DIGITS after → VALID
   Example: "380689098599" = 380 (3 chars) + 9 MORE = VALID (transform to +380)

✅ IF starts with "0" AND has exactly 9 MORE DIGITS after → VALID
   Example: "0689098599" = 0 + 9 MORE = VALID (transform to +380)

❌ IF none of above → INVALID

STEP 3: NORMALIZE TO E.164
──────────────────────────
If valid, transform to "+380XXXXXXXXX" format:
• If already "+380XXXXXXXXX" → keep as is
• If "380XXXXXXXXX" → prepend + → "+380XXXXXXXXX"
• If "0XXXXXXXXX" → remove first 0, prepend +380 → "+380XXXXXXXXX"
